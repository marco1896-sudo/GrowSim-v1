# Neutral Ui Background

## Purpose
Neutrales UI-Hintergrundmotiv ohne Ablenkung.

## Style
Photorealistic, premium game-art realism, clean materials, no cartoon aesthetics.

## Composition
Single clear subject, centered or rule-of-thirds framing, readable silhouette.

## Lighting
Soft cinematic key light + subtle rim light, consistent with game environment.

## Technical constraints
- No text artifacts
- No watermarks
- Consistent perspective
- Clean edges for downstream processing

## Export format
PNG preferred (alpha if needed), 2048px master + 1024px mobile derivative.

## Negative prompts
cartoon, anime, lowres, blurry, noisy, watermark, text fragments, oversaturated neon, deformed geometry
